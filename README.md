Coders of Delhi – Data Analysis Project

This project is a hands-on walkthrough of the core data analysis workflow using a social-network–style dataset called Coders of Delhi.
The goal is simple: start from raw JSON data and gradually build logic to clean it, analyze relationships, and generate meaningful recommendations.

----------------------------------------------------------------------------------------------------------------------------------------------------------

What this project covers
The project is structured as progressive Jupyter notebooks, each focusing on a specific concept that builds toward real-world data analysis and recommendation systems.

**KEY ASPECTS COVERED** -->>
Work with JSON data,
Clean and sanitize messy datasets,
Use Python data structures effectively,
Model social graphs (users, friends, pages),
Build basic recommendation logic,
Think in terms of time and space complexity.
